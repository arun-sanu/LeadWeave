# OpenAPI / Swagger Documentation — LeadWeave

## When to invoke this skill

- When adding a new endpoint to a Controller
- When modifying the request body (DTOs) or response payload of an existing endpoint
- When you are asked to update API documentation

## Guidelines

1. **Controller Decorators**: Ensure every controller has an `@ApiTags('Group Name')` to group endpoints logically.
2. **Endpoint Decorators**: Every endpoint method must have:
   - `@ApiOperation({ summary: 'Short description' })`
   - `@ApiResponse({ status: 200, description: 'Success response meaning' })`
   - Document error cases with `@ApiResponse({ status: 400, description: 'Bad Request' })` etc.
3. **DTO Documentation**: All fields in Data Transfer Objects must have `@ApiProperty()`.
   - Use `@ApiProperty({ example: '123', description: 'The ID' })` to provide rich examples in the Swagger UI.
   - For optional fields, use `@ApiPropertyOptional()`.
4. **Security**: Ensure authenticated routes have `@ApiSecurity('api_key')` or `@ApiBearerAuth()` applied, depending on the current auth scheme of the controller.

Following these rules ensures the `openapi.json` generated by NestJS stays perfectly in sync with the implementation.
