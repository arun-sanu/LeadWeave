# Community Integrations

Third-party integrations and adapters built by the community on top of LeadWeave's REST API.

> **Looking for Chatwoot, Typebot, and other first-party integrations?** Those ship as official
> sandboxed plugins on the Integration Fabric — see the [LeadWeave-plugins](https://github.com/arun-sanu/LeadWeave-plugins)
> catalog. This page lists only community-built projects.

> ⚠️ **These projects are community-maintained and are not affiliated with or endorsed by LeadWeave.**
> They may lag behind LeadWeave API changes. Verify compatibility and review the source before using
> them in production.

| Integration         | Platform                                                      | Source                                                                                                                                         | Notes                                                                                                                                  |
| ------------------- | ------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| **ioBroker.leadweave** | [ioBroker](https://www.iobroker.net/) (home / IoT automation) | [ThorstenBoettler/ioBroker.leadweave](https://github.com/ThorstenBoettler/ioBroker.leadweave) · [npm](https://www.npmjs.com/package/iobroker.leadweave) | Send text / image / video / audio / document messages to chats and groups through LeadWeave's REST API, with Blockly blocks. Early stage. |

Maintain an integration built on LeadWeave and want it listed here? Open a PR adding a row (or an issue), including the repository link and a one-line description.

For the first-party n8n nodes, see [n8n Integration](./22-n8n-integration.md).
